## 0. 需求与实测前提（不是推断）

- 自动订阅占订阅总量 **421/1191 = 35%**，其匹配链路最弱一环是**没有校准的启发式阈值**。
- 6 例探针实测（`backend/scripts/jev_ab_probe.py`）：现有启发式 **4/6 错判**（4 个反例全部误订），JEV `noul`+`choice` **6/6 正确**；反例概率 0.02~0.10、正例 0.97~0.98（分离度宽）；单次延迟 0.88~0.94s，成本 ≈$0.00001/次（$0.042/M input，output 免费）。
- 误订根因三条（`services/auto_subscribe/pipeline/matching.py`）：
  1. `:96` 中文阈值「共同汉字≥2 且占比≥30%」→「海上心狱/海上钢琴师」判相似
  2. `:64` 兜底 `_best_by_vote` 取**评分最高**当**最对的** → 真实条目不在候选时返回无关热门条目而非 `None`（最危险）
  3. `:137` `_strip_season` 剥副标题后精确命中同 IP 另一条目（电影版 → 剧版）
- 另一条已死路径：`pipeline/search.py:105 _ai_assisted_search` 用生成模型做**判定**，09-23~09-30 **连续 8 天 0 成功、全是 503**，静默降级无告警 → 上线前后都必须可见化。

量级：JEV 只在 fallback 路径调用 → 调用量 = 冷门/歧义条目数 ≪ 每日候选量（activity_logs 每日 18~74 条）。

## 1. 组件边界

- 新增 `services/decision.py` = **唯一判定入口**，负责 HTTP（**必须走 `core/http_client.py`**）。
- `pipeline/matching.py` 只**调用**它做校验，不承担 HTTP、不读配置细节。
- 开关放 `ai_config`（前端已有 AI 配置页），默认**关**。
- 共享脚本 `~/.hermes/scripts/jev.py` 用裸 `urllib`，**禁止直接复制进项目**（违反 `STANDARDS.md` 铁律）；只保留策略：IPv4 优先、每地址 8s 超时、整体重试 3 次（1s/2s 退避）。
- 无状态：JEV 不落库、不建表、不持有会话。

## 2. 接口契约

| 项 | 契约 |
|---|---|
| 触发时机 | **仅当** `pick_best` 精确匹配（阶段 1/2/3）全部失败、进入阶段 4/5 **之前**。精确匹配是对的、免费的、零延迟，不花 JEV 的钱 |
| 入参 | `{待订阅:{标题,年份,类型}, 搜索结果:[{序号,标题,年份,类型,评分}]}` |
| 出参 | `{same_work: 概率, which: 候选 key, confidence}` |
| 耗时预算 | p95 < 2s（实测 0.9s）；超时 → 降级 |
| 判定（代码侧） | `same_work ≥ 0.7` **且** `which != none` → 采纳；`≤ 0.3` → 拒绝；中间区间 → **保留旧启发式结果** + warn |
| 降级 | **fail-closed**：JEV 不可用/超时/异常 → 回退旧启发式继续跑；**同时** `logger.error` + 降级计数器（activity_logs 或 metrics），可查"降级持续多久" |
| 灰度 | `shadow=true` 只记 JEV 判定 vs 实际采纳的差异（含概率）不生效；建议跑满 7 天后切生效 |
| 版本 | 阈值标定后 pin 到响应 `model` 的真实版本号（如 `jev-1.13.0`），**禁止 `jev-latest`** |

## 3. 数据格式

- `questions` 用扁平 key：`same_work__0` / `which__0`（数组下标后缀）。
- **`choice.criteria` 必须是 dict**（传 list → 422）；`score.criteria` 才是有序 list。
- 阈值与 pin 版本号写进 `ai_config`（不是硬编码在代码里），便于无发版调整。
- state 里**禁止**塞标题元信息 / 测试标注（实测：写「本条为人工注入」把 0.93 打成 0.17，模型会字面理解）。

## 4. 量级约束

- 调用量 ≈ fallback 条目数（日级个位数~十几），成本可忽略；不需要限流，但要有日调用计数。
- 批量回放用 `jev.py map --concurrency 8`（实验阶段）。
- 单点失败不得影响主流程（超时预算 2s 内必须返回可用结论，否则降级）。

## 5. 非目标（红线）

- 不做算术/计数/日期序（年份 ±1、集数统计留在代码里 —— 两路 AND，不是把数值比较交出去）。
- 不让它生成文本（它不是生成模型）；`_ai_assisted_search` 的"生成标准化名"部分保留 LLM 或改规则。
- 不替换 `pick_best` 阶段 1/2/3 精确匹配。
- 不 pin `jev-latest`。
- 不把标题元信息/测试标注塞进 state。
- 禁止无告警的静默降级。
- 禁止裸 `urllib`/`httpx`/`requests`。

## 6. 前置门槛与 GO/NO-GO 判据（4A）

6 例只是探针，**不是标定**。上线前必须用真实语料回放：

- 样本：从 `activity_logs`（4811 条）导出自动订阅/退订对，目标 ≥300 条；**必须重建候选集**（10 张表都不存搜索结果快照，日志只记条数与结果，不记候选列表）。
- 局限声明：TMDB 现状 ≠ 当时结果 → 结论是**方向性验证**，不是精确复现。
- 回放时**关闭 AI 辅助**（该路径 503 全失败），纯对比 `pick_best` 启发式 vs JEV。

**GO 门槛（三条全过）**：

1. 误订率（FP/总数）相对现有方案**下降 ≥50%**
2. 正标签召回**不低于现有方案 − 5pp**
3. 单次成本 < $0.001、p95 延迟 < 2s

不达标 → 只上影子模式，不切生效；差得远 → 报 NO-GO 并给替代建议（如仅修 `_best_by_vote` 兜底 + 中文阈值）。

## 9. 阈值与指令标定（2026-10-02，architect 复算）

**结论：`same_work` 阈值 0.5 → 0.75（可用带 [0.65, 0.85]），且必须同时把指令换成 v3（新增"纯书写形式差异不影响判定"）。只调阈值救不了漏订。本节覆盖 §2 判定行的 0.7/0.3 口径。**

依据：同一批 4A 产物（`/tmp/jev_replay`）**零新增判定成本**复算——702 条 A 实际采纳的兜底样本，标签口径 = `truth_ids`（候选标题归一化后与源标题完全相等）。

1. 概率极双峰：672 条真同作品中 552 条 ≥0.98、其余 0.91~0.97；**生产指令 v2 下有 5 条真同作品被压到 0.25~0.39**（老师您辛苦了 / 伦敦合伙人 / 说唱巅峰对决2026 / 潮汐低语 / 直到T恤干透）。
2. v2 阈值曲线变化点（逐 0.01 扫描）：τ∈[0.40,0.45] fp=4 → [0.46,0.74] fp=2 → **[0.75,0.86] fp=0，最优平台** → 0.87 起召回开始掉。**0.5 既不在最优平台、距 0.46 边界又只差 0.04 → 不稳。**
3. 指令是主因：v3（增加"标点/空格/全角半角/书名号引号写法/数字写法如十与10/感叹号位置等纯书写差异不影响判定；上映年口径差异也不算不同"）把那 5 条抬到 **0.92~0.97**，并把 3 组标点变体（银魂 吉原大炎上 / 年会不能停2！ / "你们先走我断后"十年→10年）从 0.22~0.74 抬到 0.88~0.97。
4. 净效果（经人工判读）：**真实漏订 5 → 0、真实误订 0 → 0**。v3+0.75/0.80 下"标签不同名却放行"的 6 条**经判读全部是同作品**（是标签口径把它们误标，JEV 判对了）；"同名却拦下"仅剩 1 条 OOD 样例（逃亡者 0.75/0.79——生产走精确匹配、根本不进闸门）。
5. 抖动实测（v3 重复跑两遍 515 states）：平均 |Δ|=0.0019、p95=0.01、最大 0.08；**0.75/0.80 处判定翻转 0 条**。v3 下的空白山谷 = **[0.61, 0.87]**。
6. 已知残留成本（接受）：`魔法少女奈叶 EXCEEDS复仇枪焰 → …Gun Blaze Vengeance`（译名差异，0.60）会被拦；`令和妖神斑小姐 → 令和的斑小姐`（0.51）仍拦（判为不同作品，正确）。
7. 落地要求：阈值改 `ai_config`（禁硬编码）、指令改 `services/decision_payload.py` 常量；改完**用同一批 515 states 复跑出对照表**才算验收（脚本：`jev.py map --input items_veto.jsonl --questions-file questions_v3.json`）。
8. 红线不变：闸门**不读 `which`**；v3 只放宽"书写形式"，**副标题/版本（电影版vs剧集版、剧场版vs TV版）/季数/类型差异仍判不同作品**。
